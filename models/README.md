# Machine Learning Models

This folder is intended for storing trained machine learning models.

## Current Model

The primary model used in this project is:

- Random Forest Classifier

## Machine Learning Type

Supervised Learning.

## Problem Type

Binary Classification.

The model predicts whether a customer will:

- Remain with the company
- Churn from the company

## Features

The model uses:

- Age
- Tenure
- Monthly Charges
- Total Spend
- Support Calls
- Contract Type
- Payment Method
